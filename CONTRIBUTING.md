# Contribution Guide

Thanks for your interest in contributing to this project! To maintain a collaborative and orderly environment, follow these recommendations:

## How to contribute

1. **Forkea the repository**and creates a branch for your contribution.
2. **Make your changes**following good development practices.
3. **Add tests**If your contribution modifies or adds functionalities.
4. **Make sure your code pass the existing tests**before sending your Pull Request.
5. **Clearly describe your contribution**in the Pull Request message.

## Code style

- Follow the convention of styles defined in the project.
- Use descriptive names for variables and functions.
- Document your code when necessary.

## Report errors

If you find an error, open an ISSUE detailing:

- Steps to reproduce the problem.
- Expected and observed behavior.
- Relevant information of the environment (operating system, Node version, etc.).

## Improvement proposals

If you have ideas to improve the project, open an ISSUE or discuss it in the corresponding channel before starting to work.

## Code of Conduct

Remember to follow the [code of conduct](./CODE_OF_CONDUCT.md) to maintain a respectful and collaborative environment.

Thanks for helping to improve this project!
